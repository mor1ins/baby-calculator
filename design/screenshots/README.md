# Основные сценарии «Тише»

Пять скриншотов текущего приложения, версия `400a733`, сняты 5 октября 2026 года.
Ширина экрана 390 CSS-пикселей, масштаб PNG 2×. Для графиков высота увеличена, чтобы полностью показать карточки и форму настройки. Использованы демонстрационные данные;
реальные аккаунты и записи пользователей не затронуты.

| Скриншот | Что показывает |
| --- | --- |
| [Главный экран](01-today-awake.png) | Прогноз следующего сна, кнопка «Уснул» и показатели дня |
| [Лента дня](02-timeline-previous-night.png) | Предыдущая ночь, дневной сон, бодрствование и заметки |
| [История](10-history.png) | Календарь и показатели прошлых дней |
| [Мои графики](11-schedules.png) | Два разных плана, выбор по умолчанию и создание нового графика |
| [Настройка графика](13-schedule-editor.png) | Полная форма: длительности сна и бодрствования, добавление снов, режим применения и сохранение |
