# Тише — мобильный дизайн дневника сна

Рабочее название: **«Тише»**. Базовый дизайн первой версии дополнен предложением статистики, CSV и публичного отчёта от 10.10.2026; это интерактивный прототип, не готовый frontend. Весь прототип находится в этом каталоге и не подключен к backend.

## Открыть

Откройте `index.html` в браузере: собранные React и Konsta UI лежат в `assets/`, для просмотра установка зависимостей и интернет не нужны. На смартфоне интерфейс занимает всю ширину; на большом экране слева появляется навигация по макету.

Для просмотра со смартфона в одной локальной сети можно запустить из корня репозитория:

```sh
python3 -m http.server 8081 --directory design --bind 0.0.0.0
```

Затем открыть `http://<локальный-IP-компьютера>:8081`. Сервер публикует только каталог design. Остановить — Ctrl+C. Если достаточно просмотра на компьютере, можно использовать `--bind 127.0.0.1`.

## Состав

- `index.html` — оболочка прототипа.
- `styles.css` — визуальная система и мобильная адаптация.
- `reporting.js` — новые сценарии статистики, CSV и публичного снимка на отдельном наборе примеров.
- `AUDIT.md` — сверка с текущим frontend и известные расхождения старого макета.
- `prototype.js` — демонстрационные экраны и переходы без API и хранения данных.
- `SPEC.md` — визуальные правила, поведение компонентов и требования к будущей реализации.
- `previews/` — снимки экранов мобильного прототипа и общий вид на компьютере.

## Демонстрационные данные и ограничения

Основной пример: 3 октября 2026 года, 14:20, пробуждение в 06:30, первый сон 10:50–12:10. По пользовательскому графику следующий сон ожидается в 16:50–17:10, ночной — с 20:10 до 06:10. Дневной сон на сейчас — 1:20; дневное бодрствование — 6:30. Плановый цикл — 23:40, автоматического дополнения до суток нет.

Время в прототипе фиксировано, при сохранении окончания дневного сна может сдвигаться вперед. Сохранение изменяет только данные в памяти страницы: после перезагрузки восстанавливаются примеры. Редактирование шаблона не заменяет уже выбранный снимок плана; для применения изменений нужно выбрать график на сегодня снова.

Прототип показывает две дневные дремоты; дополнительные дневные сны и произвольная история не реализованы. Ночной сон — отдельное демонстрационное состояние; запись ночи не пересобирает весь пример дневника. Экран первого дня открывает фиксированный пример после формы. Прошедшие дни — примеры завершенной истории с редактированием снов и пересчетом итогов. Все административные дневники используют один демонстрационный набор, а роли переключаются вручную. Это не реализация авторизации, прав доступа или бизнес-расчетов.

Копирование/архивирование шаблонов, удаление сна, перепривязка заметки, восстановление после сетевых ошибок и произвольное число интервалов уже реализованы в приложении и описаны в SPEC.md; в старом прототипе остаются ограниченными. Базовые границы цикла уже приняты в API v1; SPEC.md приведён в соответствие. Новые разделы 12–14 — предложение для реализации, а не уже существующие серверные функции.

## Проверка

Прототип проверяется в браузере на ширинах 320, 360, 390 и 430 px и в настольном режиме. Основные проверки: отсутствие горизонтального скролла, переходы, формы сна/графика, административный режим без редактирования, сообщения об ошибках. Скриншоты сняты при ширине 390 px, плотности 2×; это изображения макета, не работающего продукта.

Каталог намеренно отделен от frontend: его скрипт — средство обсуждения дизайна. При переносе в React использовать `frontend/AGENTS.md`: слои, DI, шину, репозитории и тесты. Не переносить демонстрационное состояние, произвольное переключение ролей и упрощенные расчеты в продукт.

## Исправление записей

В временной линии нажмите «Изменить интервал»: доступны начало, окончание и заметка, предварительный просмотр длительности и отмена. У текущего сна можно сохранить незаполненный конец. Проверяются пересечения, порядок времени и будущие завершенные записи; ошибочные значения не сохраняются.

«Исправить границы» у бодрствования открывает выбор соседнего сна, который нужно поправить. Само бодрствование не вводится вручную. Исправления доступны и в истории. Администратор по-прежнему видит только данные без действий изменения.

Снимки новых панелей: `previews/10-edit-interval.png`, `previews/11-edit-wake.png`. В браузере дополнительно проверены пересчет метрик, сохранение заметок, исправление утренней границы, открытый сон, переход через полночь, отмена, пересечения и отсутствие редактирования в административной истории.

## Ночной сон

Быстрые отметки «Проснулся / заплакал», журнал и счётчики удалены из макета по результатам использования. На ночном экране остаются длительность, завершение сна и заметка. События также исключены из статистики, CSV и публичного отчёта.

## Расширенная статистика и профиль малыша

Новый вариант для обсуждения: `index.html#statistics` → «Обзор / Ритм суток / День → ночь / Изменения». В «Ритме суток» выберите дату и нажмите «Записать укладывание»; во вкладке изменений можно добавить свою запись и увидеть сравнение до/после. Все вкладки учитывают общий период.

Цель семьи, уточнение ночных событий и полнота наблюдений не добавлены.

`insights.js` содержит эти новые демонстрационные сценарии. Профиль и приватные заметки исключены из публичного снимка. После перезагрузки восстанавливаются примеры. Новые скриншоты: `previews/20-daily-rhythm.png`, `21-day-night.png`, `22-changes.png`, `23-child-profile.png`, `24-child-editor.png`, `25-rhythm-dark.png`.

## Полная переработка экранов · итерация 05

Обновлены структура «Сегодня», ночной режим, история и завершённый день, карточки и редактор графиков, профиль, административный список, вход, регистрация и начальные/заблокированные состояния. Статистика и публичный отчёт используют ту же систему компонентов. Формы получили общий стиль и группировку полей. Возраст по-прежнему вычисляется исключительно из даты рождения.

Актуальные снимки всех основных экранов в обеих темах: `screenshots/full-*.png`. Проверка `node design/verify-screens.cjs` охватывает 11 экранов на ширинах 320, 390 и 768 px, редактирование/создание графика, запись сна, поиск и режим чтения администратора, первый день и вход. `node design/verify.cjs` отдельно проверяет статистику, экспорт, публичный снимок, профиль малыша и доступность. Это интерактивный макет; изменения в рабочее приложение не перенесены.

Кнопка «Уснул» открывает прокручиваемый барабан «Только что» и 1–60 минут назад (по умолчанию 5) с предпросмотром времени. Подтверждение записывает фактическое начало дневного или ночного сна; отмена не меняет записи. Пересечение с предыдущим сном запрещено. Проверка: `node design/verify-start-sleep.cjs`.

Типографика: единый Manrope из Google Fonts (локальный variable TTF, веса 200–800, лицензия SIL OFL рядом в `fonts/`). Заголовки без засечек, размер 30 px на страницах и 22 px в формах; основные действия 15 px, пояснения 13 px. Для времени включены табличные цифры. Источник: https://github.com/google/fonts/tree/main/ofl/manrope.

Обзор статистики сокращён до сводных показателей и пояснения расчётов: диаграмма «Дневной сон и ночь» и таблица «По дням» убраны. Подробная шкала доступна во вкладке «Ритм суток». Публичный отчёт сохраняет детализацию по дням, поскольку у него нет вкладок.

На главной перед кнопкой «Уснул» добавлено «Начать укладывание». Состояние показывает время начала и прошедшие минуты, поддерживает отмену и сохраняется при переходах по макету. Засыпание завершает укладывание, его начало сохраняется вместе со сном и показывается в ленте. Для активного укладывания доступно «Только что» в барабане; заднее число не может предшествовать началу укладывания. Статистика по-прежнему использует отдельный демонстрационный набор данных.

Активное укладывание можно «Завершить без сна». Попытка с началом, окончанием и длительностью остаётся в ленте внутри бодрствования; запись сна не создаётся. Можно сразу начать новую попытку, её длительность считается отдельно. Крестик отменяет ошибочно запущенное укладывание без сохранения. Как и остальные записи макета, попытки хранятся до перезагрузки.

Минималистичная концепция удалена. В основной макет перенесены только UX-изменения: основное действие «Начать укладывание», дополнительное «Уже уснул»; во время укладывания главный показатель — его длительность, доступны «Уснул», «Завершить без сна» и явная отмена без сохранения. Цвета, шрифты и оформление основного макета сохранены. Барабан «Только что» / 1–60 минут, исключение ночных отметок и сокращённый обзор остаются в основном макете.

Статистика — только просмотр: во всех четырёх вкладках убраны добавление, редактирование и удаление записей. Карточка малыша не открывает редактор; существующие обстоятельства дня и укладывание показываются текстом. Выбор периода и дня, раскрытие деталей, экспорт CSV и управление публичной ссылкой сохранены. Профиль редактируется на странице профиля.

Карточка малыша в статистике показывается только получателю публичного отчёта. Имя (32 px) и возраст (20 px) увеличены; круглый аватар занимает 75% внутренней ширины карточки. При создании ссылки имя, отображаемый возраст и фото фиксируются в снимке. Дата рождения, пол, сведения о родителе и личные заметки не включаются. В собственной статистике карточки нет. Это изменение заменяет прежнее исключение имени/возраста/фото из публичного отчёта.

Публичный отчёт теперь содержит все четыре раздела: обзор, ритм суток с выбором дня, сравнение дня и ночи и изменения режима. Данные временных интервалов и изменения режима копируются в снимок выбранного периода; публичные вкладки и выбранный день независимы от вкладок родителя. Личные заметки дня/профиля исключены, редактирование недоступно. Проверка: `node design/verify-public-statistics.cjs`.

Во вкладке «День → ночь» список раскрываемых дней заменён календарём с переключением месяцев в пределах периода. Дни с записями доступны для выбора; показатели выбранного дня и следующей ночи показаны под календарём. Полная таблица сравнения сохранена. Календарь работает также в публичном снимке.

В публичном отчёте доступна кнопка «Скачать CSV»: экспортируется опубликованный период из снимка, без личных заметок и без возможности изменить диапазон.

Обзор статистики: пояснение о средних расположено перед карточками, карточки оформлены одинаково. Удалены ссылка «Посмотреть расписание по дням» и блок «Как считаются показатели». Экспорт и создание публичной ссылки доступны через меню «⋯» в заголовке. В публичном отчёте сохранена отдельная кнопка CSV.

## Konsta UI

Общие элементы всех экранов переведены на реальные React-компоненты Konsta UI 5.5: `Button`, `Card`, `List`, `ListItem`, `ListInput`, `Segmented`, `SegmentedButton`, `Tabbar`, `TabbarLink`. Подключён скилл `konsta-ui` от Cap-go; настройка сборки сверена с актуальной документацией Konsta 5 (Tailwind 4, импорт темы вместо старого `konsta/config`).

`src/mobile-ui.jsx` — адаптер презентационного слоя. Он переводит локальные шаблоны существующего демонстрационного движка в React-дерево под `KonstaProvider`; бизнес-сценарии и делегирование событий остаются в `prototype.js`, `reporting.js`, `insights.js`. Это промежуточное устройство интерактивного макета, не архитектура для переноса в продукт. Барабан, календарь, диаграммы и нативный модальный dialog остаются специализированными элементами; формы внутри dialog используют Konsta. Сохраняются клавиатурное управление, фокус и все прежние проверки.

Переключатель iOS / Android расположен в боковой панели на компьютере и в «Профиль → Сценарии макета» на телефоне: он меняет оформление сразу, без перезагрузки и сброса записей. Выбор отражается в адресе и сохраняется при обновлении страницы. По умолчанию Android получает Material, остальные устройства — iOS. Для сравнения доступны `?platform=ios#day` и `?platform=android#day`. Светлая/тёмная/системная тема выбирается в профиле. Шрифт Manrope и акцент «Тише» сохранены.

После правок исходников:

```sh
npm ci --prefix design
npm run build --prefix design
```

Сборка обновляет локальные `assets/mobile-ui.js`, `assets/mobile-ui.css` и версии ресурсов в `index.html`. Новая проверка `node design/verify-mobile-ui.cjs` покрывает обе платформы, темы, ширины 320/390/430, доступность полей и расположение навигации поверх содержимого.

Во вкладке «День → ночь» оставлены календарь и данные выбранного дня. Полная таблица сравнения, пояснение о ночном интервале и секция «От дня к дню» удалены в личном и публичном просмотре.
