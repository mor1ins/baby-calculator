# Тише — мобильный дизайн дневника сна

Рабочее название: **«Тише»**. Дизайн принят для первой версии; это интерактивный прототип, не готовый frontend. Весь прототип находится в этом каталоге и не подключен к backend.

## Открыть

Откройте `index.html` в браузере: установка зависимостей и интернет не нужны. На смартфоне интерфейс занимает всю ширину; на большом экране слева появляется навигация по макету.

Для просмотра со смартфона в одной локальной сети можно запустить из корня репозитория:

```sh
python3 -m http.server 8081 --directory design --bind 0.0.0.0
```

Затем открыть `http://<локальный-IP-компьютера>:8081`. Сервер публикует только каталог design. Остановить — Ctrl+C. Если достаточно просмотра на компьютере, можно использовать `--bind 127.0.0.1`.

## Состав

- `index.html` — оболочка прототипа.
- `styles.css` — визуальная система и мобильная адаптация.
- `prototype.js` — демонстрационные экраны и переходы без API и хранения данных.
- `SPEC.md` — визуальные правила, поведение компонентов и требования к будущей реализации.
- `previews/` — снимки экранов мобильного прототипа и общий вид на компьютере.

## Демонстрационные данные и ограничения

Основной пример: 3 октября 2026 года, 14:20, пробуждение в 06:30, первый сон 10:50–12:10. По пользовательскому графику следующий сон ожидается в 16:50–17:10, ночной — с 20:10 до 06:10. Дневной сон на сейчас — 1:20; дневное бодрствование — 6:30. Плановый цикл — 23:40, автоматического дополнения до суток нет.

Время в прототипе фиксировано, при сохранении окончания дневного сна может сдвигаться вперед. Сохранение изменяет только данные в памяти страницы: после перезагрузки восстанавливаются примеры. Редактирование шаблона не заменяет уже выбранный снимок плана; для применения изменений нужно выбрать график на сегодня снова.

Прототип показывает две дневные дремоты; дополнительные дневные сны и произвольная история не реализованы. Ночной сон — отдельное демонстрационное состояние; запись ночи не пересобирает весь пример дневника. Экран первого дня открывает фиксированный пример после формы. Прошедшие дни — примеры завершенной истории с редактированием снов и пересчетом итогов. Все административные дневники используют один демонстрационный набор, а роли переключаются вручную. Это не реализация авторизации, прав доступа или бизнес-расчетов.

Копирование/архивирование шаблонов, удаление сна, перепривязка заметки, восстановление после сетевых ошибок и произвольное число интервалов описаны в SPEC.md как состояния для будущей реализации. Дизайн не меняет утвержденные требования PLAN.md и не утверждает автоматически открытые вопросы о границах дня.

## Проверка

Прототип проверяется в браузере на ширинах 320, 360, 390 и 430 px и в настольном режиме. Основные проверки: отсутствие горизонтального скролла, переходы, формы сна/графика, административный режим без редактирования, сообщения об ошибках. Скриншоты сняты при ширине 390 px, плотности 2×; это изображения макета, не работающего продукта.

Каталог намеренно отделен от frontend: его скрипт — средство обсуждения дизайна. При переносе в React использовать `frontend/AGENTS.md`: слои, DI, шину, репозитории и тесты. Не переносить демонстрационное состояние, произвольное переключение ролей и упрощенные расчеты в продукт.

## Исправление записей

В временной линии нажмите «Изменить интервал»: доступны начало, окончание и заметка, предварительный просмотр длительности и отмена. У текущего сна можно сохранить незаполненный конец. Проверяются пересечения, порядок времени и будущие завершенные записи; ошибочные значения не сохраняются.

«Исправить границы» у бодрствования открывает выбор соседнего сна, который нужно поправить. Само бодрствование не вводится вручную. Исправления доступны и в истории. Администратор по-прежнему видит только данные без действий изменения.

Снимки новых панелей: `previews/10-edit-interval.png`, `previews/11-edit-wake.png`. В браузере дополнительно проверены пересчет метрик, сохранение заметок, исправление утренней границы, открытый сон, переход через полночь, отмена, пересечения и отсутствие редактирования в административной истории.

## Ночные пробуждения и плач

Откройте `index.html#night` или «Профиль → Ночной сон». Крупная кнопка «Проснулся / заплакал» добавляет отметку одним нажатием, увеличивает счётчик и сохраняет время. Есть отмена последней отметки и журнал с удалением отдельных событий. «Завершить ночной сон» — отдельное действие: короткая отметка сон не останавливает.

Счётчик и журнал остаются после завершения ночи; при изменении границ события не теряются. В истории 2 октября показаны два примера отметок, администратору журнал доступен только для чтения. События разных снов независимы. Время нажатий в макете фиксировано на 23:10; данные сохраняются только до перезагрузки.

Снимки: `previews/12-night-events.png` и `previews/13-night-event-log.png`.
