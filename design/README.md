# Тише — интерактивное демо

Автономный макет дневника сна, актуализированный по основному приложению 13 октября 2026. Публичный адрес: https://demo.tishe-doma.ru. Проверочное окружение: https://dev.demo.tishe-doma.ru.

## Открыть и собрать

`index.html` можно открыть прямо в браузере: собранные ресурсы находятся в `assets/`. Для пересборки выполните в `design/`:

```sh
npm ci
npm run build
```

Для просмотра с телефона запустите из корня проекта `python3 -m http.server 8081 --directory design --bind 0.0.0.0` и откройте адрес компьютера с портом 8081.

## Что проверить

- `#day`: дневник, укладывание, начало сна, «Добавить событие», редактирование интервалов и заметки.
- `#night`: ночное бодрствование, возвращение ко сну, пробуждение, редактирование в ленте. Активная ночь сохраняется при переходе на «Сегодня».
- `#statistics`: период, обзор, ритм суток, расчёты под выбранным днём и изменения режима. В меню действий — непосредственная загрузка Excel и публичный снимок выбранного периода.
- `#history`, `#schedules`, `#profile`: история, графики, профиль малыша и оформление.
- `#admin`, `#login`, `#register`, `#blocked`: демонстрационные административные и входные экраны.

Светлая/тёмная тема и платформенное оформление доступны в профиле. На большом экране также появляется навигация по макету.

## Данные и ограничения

Демо не подключается к API и не сохраняет данные между перезагрузками. Основная дата — 3 октября 2026; статистика использует независимый набор примеров за 26 сентября–3 октября. Публичная ссылка — локальная имитация снимка, а не опубликованный персональный отчёт. Не вводите реальные учётные данные.

В Excel выгружаются факты выбранного периода, даты расположены по столбцам; личные заметки включены всегда, публичные файлы их не содержат. `src/reportWorkbook.js` — копия одноимённого форматировщика основного frontend: при изменении формата синхронизировать обе реализации.

Сверка с приложением и ограничения: `AUDIT.md`. Исторические решения: `SPEC.md`; при расхождениях актуальная сверка имеет приоритет. Не переносить демонстрационные расчёты и переключение ролей в рабочее приложение.

## Проверка и публикация

Из корня, после установки зависимостей `tests/` и Chrome:

```sh
node design/verify-screens.cjs
node design/verify-mobile-ui.cjs
node design/verify.cjs
node design/verify-start-sleep.cjs
node design/verify-public-statistics.cjs
node design/verify-product-parity.cjs
```

Проверяются мобильные размеры, обе темы, формы, доступность событий во всех режимах, ночное бодрствование, укладывание, календарные границы графика, Excel и изоляция публичного снимка. Доставка описана в `deploy/demo/README.md`: merge в main → новая сборка demo dev → проверка → продвижение того же digest на публичное демо.
