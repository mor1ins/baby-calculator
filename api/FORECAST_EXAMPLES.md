# Утвержденные примеры прогноза v1

Пункт P-03 утвержден пользователем 3 октября 2026 года. Эти примеры задают ожидаемое поведение будущего сервиса расчета; реализация и автоматические тесты относятся к C-01–C-03 и T-05.

## Общие условия

Дата цикла — 2026-10-03, часовой пояс — `Europe/Moscow`, утренний подъем — 06:30. Все времена ниже локальные; окончание ночи относится к 2026-10-04. В API моменты передаются с часовым поясом, ответы — в UTC.

Снимок графика: бодрствование 4:20 → дневной сон 1:20 → бодрствование 4:40 → дневной сон 0:20 → бодрствование 3:00 → ночной сон 10:00. Сценарии независимы, каждый использует этот снимок.

## Входы и ожидаемые результаты

| ID | Факты и момент расчета | Ожидаемый прогноз |
| --- | --- | --- |
| F01 — по плану | Сейчас 06:30, утренняя граница известна, снов этого цикла пока нет | Дневные сны 10:50–12:10 и 16:50–17:10; ночь 20:10–06:10 |
| F02 — завершенный сон длиннее плана | Сейчас 12:30; первый сон 10:50–12:30 | Второй сон 17:10–17:30; ночь 20:30–06:30 |
| F03 — текущий сон превысил план | Сейчас 12:30; первый сон начался в 10:50, конец не указан | Текущий сон сохраняет `end=null`, `expected_end` соответствует 12:10; превышение 20 минут. Условный прогноз: второй сон 17:10–17:30, ночь 20:30–06:30 |
| F04 — пропущен второй сон | Первый сон 10:50–12:10; второго нет; сейчас 18:00, пользователь начал ночной сон | Оставшийся дневной прогноз отсутствует; текущая ночь началась в 18:00, ожидаемый подъем 04:00 |
| F05 — лишний дневной сон | Первые сны 10:50–12:10 и 16:50–17:10; третий сон 18:00–18:20; сейчас 18:20 | После третьего сна применяется последнее плановое бодрствование 3:00; ночь 21:20–07:20, отображается расхождение с графиком (`extra_naps`) |

## Правила проверки

- В F03 превышение обозначается `plan_exceeded`. Условная граница завершения текущего сна для дальнейшего прогноза равна моменту расчета; она не сохраняется как фактический конец сна. Пока сон продолжается, будущий прогноз сдвигается вместе с текущим временем.
- Пропуск сна автоматически не определяется. До начала ночи или смены графика сохраняется очередность плана. F04 переключает прогноз на ночь по фактической записи пользователя.
- Завершенные интервалы не сдвигаются. Прогнозные длительности не входят в фактические метрики.
- Расчет получает явно заданное текущее время; результаты не должны зависеть от часов машины, запускающей тесты.
- Будущие тесты T-05 должны покрывать все пять сценариев, даты после полуночи и преобразование локального времени в UTC. Проверка схем через `api/validate.py` не заменяет эти тесты расчета.
