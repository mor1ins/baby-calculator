# Правила выпуска

- На production разрешено выкатывать только код, собранный из `main`.
- PR и другие ветки можно выкатывать только на dev. Запуск workflow из `main` сам по себе не означает, что приложение собрано из `main`.
- Перед prod: merge в `main`, успешная новая сборка и выкладка `main` на dev, проверка этого релиза, затем продвижение тех же digest в prod по запросу пользователя.
- Даже после merge нельзя продвигать старую PR-сборку. Релизы без подтверждённого происхождения не допускаются.
- Не обходить проверки источника релиза. Подробности — в `deploy/README.md`.
